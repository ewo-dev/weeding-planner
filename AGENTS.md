# Project Instructions

## Project
This is a web application for creating wedding seating plans.

## Tech Stack
- Next.js
- TypeScript
- Tailwind CSS
- Supabase

## Rules
- Keep the application simple and mobile-first.
- Prefer server components when appropriate.
- Do not introduce dependencies without a clear reason.
- Follow the architecture defined in `docs/`.
- Before implementing a feature, read the relevant documentation in `docs/`.

## Development
- Run lint and typecheck before considering a task complete.
- Keep components small and reusable.

## Context Efficiency

- Read only the files necessary for the current task.
- Do not reread files that were already inspected unless they may have changed.
- Prefer targeted searches over reading entire files.
- Do not inspect unrelated documentation.
- Before using bash, consider whether grep, glob, or another targeted tool is sufficient.
- Group related shell operations when practical.
- Do not create or update TODO items for trivial tasks.
- Keep the active context focused on the current task.
